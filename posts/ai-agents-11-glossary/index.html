Glossary

2026-10-11

Every term from the series in one plain sentence, alphabetically, with the post that explains it.

Term What it means Post
Agent A model given a goal, tools and know-how, working in a loop until the job is done or it needs a person 6
Agentic workflow A piece of work split into stages done by AI and people, joined by hand-offs and checks 7
AI (artificial intelligence) Computers doing tasks that seem to need human thinking 1
AI-assisted service People do the work and AI makes them faster 9
AI-first service The workflow does the work end to end; people handle exceptions and accountability 9
Autonomy level How much an agent may do without a person approving it, from "suggest" to "act alone" 6
Chain A workflow pattern where fixed steps run in order, each feeding the next 7
Checkpoint A point where a person looks at the work: a gate, an exception queue or a spot-check 7
Connector Everyday name for an MCP server: an adapter that links AI apps to one system 4
Context Everything the model can see when it answers: instructions, conversation, documents, tool results 2
Context engineering Choosing what goes into the context, and when 2
Context window The maximum amount of text the model can see at once; its "desk" 2
Cost per job AI usage plus people's review time plus overheads for one unit of work 9
Exception queue A checkpoint where only flagged items go to a person 7
Fine-tuning Further training a model on your own examples to change its default behaviour 5
Gate A checkpoint where work stops until a person approves it 7
Generative AI AI that produces new content such as text, images or audio 1
Guardrails Limits built around an agent so mistakes stay small: narrow tools, approvals, budgets, logs 6
Hallucination A confident, fluent answer that is made up 1
Harness The software that runs an agent's loop and passes results back to the model 6
Human in the loop Designing a workflow so people check or approve at chosen points 7
Instructions (system prompt) The builder's standing briefing to the model: role, rules, format; the agent's job description 2
Knowledge Your own documents, organised so an agent can look things up in them 5
LLM (large language model) Generative AI trained on vast amounts of text to read and write language 1
Machine learning Getting computers to learn patterns from examples instead of hand-written rules 1
Maker and checker A workflow pattern where one step drafts and another checks against rules 7
Manager and helpers A workflow pattern where a lead agent splits a job among helper agents and assembles the result 7
MCP (Model Context Protocol) A shared standard for connecting AI apps to tools and data, like a universal plug 4
Memory An app feature that saves notes and puts them back into the context later 2
Model The trained "brain": text and images in, text out 1
Parallel A workflow pattern where many similar items are handled at once and combined 7
Parameters The internal settings in which a model stores what it learned 1
Pilot Using an agent on real work with people checking every output 8
Prompt Any text you give the model 2
Prompt injection Hidden instructions in content an agent reads, trying to make it misbehave 4
RAG (retrieval-augmented generation) Searching your documents first and giving the model the best passages before it answers 5
Router A workflow pattern where a first step classifies the input and sends it down the right path 7
Skill A packaged procedure — instructions, examples, templates — the agent opens only when a task needs it 5
Spot-check A checkpoint where a person reviews a sample after the fact 7
Test set Real past cases with known correct answers, used to score the agent after every change 8
Token A small chunk of text, often part of a word; the unit models read and are measured in 2
Tool A single labelled action the model can ask the app to perform, such as a lookup or sending an email 3
Training The one-off process in which a model learns from data, before anyone uses it 1
User prompt What a person types to the model in the moment 2
