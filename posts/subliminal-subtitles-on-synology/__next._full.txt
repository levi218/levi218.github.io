f:T29b3,<p><em>About a 6-minute read</em></p>
<p>My setup is simple: movies get downloaded into one folder on the NAS, and Plex serves them to my phone and TV. Plex already handles the metadata, the posters and the library indexing. The one thing missing was subtitles. I wanted every new movie in that folder to get them automatically.</p>
<p><a href="https://www.bazarr.media/">Bazarr</a> is the usual answer, but it only knows about the videos that Sonarr and Radarr tell it about. To use it, I would have to set up the whole *arr stack: Sonarr, Radarr, maybe Prowlarr, each with its own database, web interface and settings. Most of that would just repeat the indexing Plex already does. Running all of it only to get subtitles is far too much.</p>
<p><a href="https://github.com/Diaoul/subliminal">Subliminal</a> is the library underneath: Bazarr itself grew out of a patched fork of it. On its own it is a command-line tool that takes a list of video files, searches several subtitle sites, scores the results against each file name and saves the best match next to the video. That is all we need. This post sets it up on a Synology NAS with one shell script and DSM&#39;s built-in Task Scheduler.</p>
<h2>What you need</h2>
<ul>
<li>A Synology NAS running DSM 7.2 or later.</li>
<li><strong>Container Manager</strong> installed from Package Center. We use it to run Subliminal inside a throwaway Python container, so nothing is installed on the NAS itself.</li>
<li>A shared folder for the script. Mine is called <code>docker</code>; any folder works.</li>
<li>Optional but recommended: a free <a href="https://www.opensubtitles.com/">OpenSubtitles.com</a> account. It is the biggest provider, and it only allows downloads when you sign in.</li>
</ul>
<h2>Step 1: Save the script</h2>
<p>Create a file called <code>subtitle-search.sh</code> in your shared folder (for example with File Station, or from your computer over SMB), and paste this in:</p>
<pre><code class="language-sh">#!/bin/sh
# Download missing subtitles and save them next to each video.
# Schedule with DSM Task Scheduler as root.

MEDIA=&quot;${MEDIA:-/volume1/Downloads}&quot;
LANGUAGES=&quot;en vi&quot;
MIN_SCORE=50 # 0-100. Lower finds more, but risks subtitles for the wrong movie.

# Optional. OpenSubtitles needs a free account for downloads.
OPENSUBTITLES_USERNAME=&quot;&quot;
OPENSUBTITLES_PASSWORD=&quot;&quot;

export PATH=&quot;/usr/local/bin:/usr/bin:/bin:$PATH&quot;

LANGUAGE_FLAGS=&quot;&quot;
for language in $LANGUAGES; do LANGUAGE_FLAGS=&quot;$LANGUAGE_FLAGS -l $language&quot;; done

# --name doubles as a lock: Docker refuses to start while the previous run is going.
# Only sidecars count as &quot;has subtitles&quot;: Plex may not show embedded tracks, and
# tracks with an unknown language block downloads for the other languages.
exec docker run --rm --name subtitle-search \
  -v &quot;$MEDIA&quot;:/media \
  -e SUBLIMINAL_PROVIDER_OPENSUBTITLESCOM_USERNAME=&quot;$OPENSUBTITLES_USERNAME&quot; \
  -e SUBLIMINAL_PROVIDER_OPENSUBTITLESCOM_PASSWORD=&quot;$OPENSUBTITLES_PASSWORD&quot; \
  -e LANGUAGE_FLAGS=&quot;$LANGUAGE_FLAGS&quot; -e MIN_SCORE=&quot;$MIN_SCORE&quot; \
  python:3.12-slim sh -c &#39;
    pip install -q --root-user-action=ignore --disable-pip-version-check subliminal==2.6.0 || exit 1
    find /media \( -name &quot;#recycle&quot; -o -name &quot;@eaDir&quot; -o -name &quot;.*&quot; \) -prune -o -type f \
      \( -iname &quot;*.mkv&quot; -o -iname &quot;*.mp4&quot; -o -iname &quot;*.avi&quot; -o -iname &quot;*.m4v&quot; -o -iname &quot;*.mov&quot; -o -iname &quot;*.wmv&quot; -o -iname &quot;*.ts&quot; \) -print0 |
      xargs -0 -r subliminal --cache-dir /media/.subtitle-search download \
        $LANGUAGE_FLAGS --min-score &quot;$MIN_SCORE&quot; --force-embedded-subtitles -v
  &#39;
</code></pre>
<p>If you edit it on Windows, make sure the file is saved with Unix (LF) line endings, or <code>sh</code> will trip over the invisible <code>\r</code> characters.</p>
<h2>Step 2: Fill in your settings</h2>
<p>Only the block at the top needs changing:</p>
<ul>
<li><strong><code>MEDIA</code></strong> is the folder to scan, as the NAS sees it. Shared folders live under <code>/volume1/&lt;name&gt;</code> (or <code>/volume2</code>, depending on which volume they are on). Every subfolder is scanned too, so pointing it at your library root is enough.</li>
<li><strong><code>LANGUAGES</code></strong> is a space-separated list of two-letter language codes. I use English and Vietnamese; each video gets one subtitle per language, saved as <code>Movie.en.srt</code>, <code>Movie.vi.srt</code> and so on — the names Plex, Jellyfin and Emby all pick up automatically.</li>
<li><strong><code>MIN_SCORE</code></strong> decides how sure Subliminal must be before it downloads. It compares the file name (title, year, season, episode, release group, resolution) against each candidate subtitle. 50 is a reasonable start; raise it if you get subtitles that drift out of sync, lower it if too many videos come back empty.</li>
<li><strong><code>OPENSUBTITLES_USERNAME</code> / <code>PASSWORD</code></strong> are your OpenSubtitles.com login. Leave them empty to use only the providers that need no account.</li>
</ul>
<p>Because the script now holds a password, keep it readable only by administrators: in File Station, right-click the file, choose <strong>Properties → Permission</strong>, and remove access for everyone else.</p>
<h2>Step 3: Schedule it</h2>
<p>Everything from here happens in the DSM web interface; no SSH needed.</p>
<ol>
<li><p>Open <strong>Control Panel → Task Scheduler</strong>.</p>
</li>
<li><p>Choose <strong>Create → Scheduled Task → User-defined script</strong>.</p>
</li>
<li><p>On <strong>General</strong>, name it <code>Subtitle search</code> and set <strong>User</strong> to <code>root</code>. Docker on DSM needs root.</p>
</li>
<li><p>On <strong>Schedule</strong>, pick <strong>Run on the following days: Daily</strong> and a quiet hour, say 3:00 AM. If new videos arrive often, you can repeat it every few hours instead.</p>
</li>
<li><p>On <strong>Task Settings</strong>, enter the command:</p>
<pre><code class="language-sh">sh /volume1/docker/subtitle-search.sh
</code></pre>
<p>Under <strong>Notification</strong>, you can also tick <strong>Send run details by email</strong> and <strong>only when the script terminates abnormally</strong>, to hear about failures.</p>
</li>
<li><p>Click <strong>OK</strong>.</p>
</li>
</ol>
<h2>Step 4: Run it once and check</h2>
<p>Don&#39;t wait until 3 AM to find out whether it works:</p>
<ol>
<li>In Task Scheduler, select the task and click <strong>Run</strong>. Confirm the prompt.</li>
<li>The first run downloads the <code>python:3.12-slim</code> image and installs Subliminal, which takes a minute or two, then searches every video. While it runs you can see a container called <code>subtitle-search</code> under <strong>Container Manager → Container</strong>; it disappears when the run is done.</li>
<li>Back in Task Scheduler, select the task and choose <strong>Action → View Result</strong>. The status should be <em>Normal (0)</em>, and the output shows each video being searched and how many subtitles were downloaded.</li>
<li>Open a video folder in File Station: the new <code>.srt</code> files sit right next to the videos.</li>
</ol>
<p>If <strong>View Result</strong> is greyed out, turn on output logging first: in Task Scheduler click <strong>Settings</strong>, tick <strong>Save output results</strong>, pick a folder, and run the task again.</p>
<p>That is it. From now on every new video in the folder gets subtitles within a day, however it got there.</p>
<h2>How the script works</h2>
<p>A few details are worth explaining, because they are what make it safe to run unattended:</p>
<ul>
<li><strong>Nothing is installed on the NAS.</strong> Each run starts a fresh <code>python:3.12-slim</code> container, installs a pinned Subliminal version inside it, and the container is deleted when it finishes (<code>--rm</code>). DSM updates cannot break it, and removing it means deleting one file.</li>
<li><strong>It never overlaps itself.</strong> The container always has the same <code>--name</code>, and Docker refuses to start a second container with a name that is taken. If last night&#39;s run on a huge library is still going, tonight&#39;s simply fails to start instead of doubling the work.</li>
<li><strong>It skips what is already done.</strong> Subliminal looks for existing sidecar files like <code>Movie.en.srt</code> and only searches for the languages that are missing. After the first run, a nightly pass over a large library is quick, and the cache folder (<code>.subtitle-search</code> inside your media folder) remembers what the providers returned so they are not asked again and again.</li>
<li><strong>It ignores embedded subtitles on purpose.</strong> <code>--force-embedded-subtitles</code> tells Subliminal not to count subtitle tracks inside the video file. Players do not always show those, and a track with no language tag would otherwise stop Subliminal from fetching any language at all.</li>
<li><strong>It stays out of Synology&#39;s system folders.</strong> The <code>find</code> command skips <code>#recycle</code> (the recycle bin), <code>@eaDir</code> (thumbnail indexes) and hidden folders, so it does not download subtitles for deleted files or thumbnails.</li>
</ul>
<h2>When it does not find anything</h2>
<ul>
<li><strong>Check the file names.</strong> Subliminal works out what a video is from its name. <code>The.Matrix.1999.1080p.BluRay.x264-GROUP.mkv</code> matches easily; <code>movie_final(2).mkv</code> does not. Renaming to <code>Title (Year)</code> helps a lot.</li>
<li><strong>Add your OpenSubtitles login</strong> if you left it empty. Without it, many popular titles have no match.</li>
<li><strong>Lower <code>MIN_SCORE</code></strong> to around 30 for older or obscure films, and accept that you may need to delete the odd wrong subtitle by hand.</li>
<li><strong>Read the log</strong> with <strong>Action → View Result</strong> in Task Scheduler. Provider errors, such as a wrong password or a daily download limit, show up there.</li>
</ul>
<h2>Bazarr or this?</h2>
<p>If you already run Sonarr and Radarr, Bazarr is the better tool: it has a web interface, upgrades subtitles over time and lets you search for one episode by hand. If you do not, this script gives you most of the value — every video gets subtitles in your languages, automatically — with no services to keep running, no database and no web interface to secure. It is one file you can read top to bottom in a minute.</p>
